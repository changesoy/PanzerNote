# 使用说明

PanzerNote 是离线、本地优先的 Markdown 与文本编辑工具。本页用于查找具体功能的操作方式。

## 文件与工作区

- 首次启动时选择用户数据目录；笔记、设置、工作区状态和游戏存档都会保存在这里。
- 使用「文件」菜单新建、打开、保存或另存为文件。文件树用于浏览笔记目录和外部文件。
- 关闭窗口或标签页时，程序会提示处理未保存内容；自动保存只用于异常恢复，不替代手动保存。
- 把**标签页**或**文件树里的条目**拖到目标文件夹上即可移动 / 复制文件（拖动时落点行会高亮，松手后先问「移动还是复制」；拖回它自己所在的文件夹不生效）。**拖的是文件夹**时直接移动该目录、不询问。移动或复制文档时会一并搬运文档引用的图片，见下文「图片资源与断链恢复」。

## 编辑与导航

- 支持多标签、分屏、语法高亮、自动缩进、括号配对、折叠、查找替换和跨文件搜索。
- Markdown 文件可以打开分屏预览；大纲面板可按标题跳转。
- 分屏预览的行宽是**独立设置**：「设置 → 记事本设置 →「预览行宽」」可选**限制行宽**（长代码行与宽表格按预览面板宽度折行，不出现横向滚动，默认）或**不限制行宽**（代码块内可横向滚动、宽表格会撑宽整页）。它与同一处的「行宽模式」（编辑器自身的换行行为）互不影响，可各自设置。
- 「视图」菜单管理文件树、大纲、跨文件搜索、命令面板和缩略图等界面。
- 打开「帮助 → 快捷键列表」可以查看或自定义快捷键；标题行右侧的「重置全部」把全部键位恢复默认。
- 按 `Esc` 可以退出子页面与面板：快捷键列表、大纲 / 跨文件搜索面板、游戏侧栏页面都会逐级退回编辑器（文件树属于主界面，不受影响）。

## Markdown 编辑辅助

以下功能位于「编辑 → Markdown 编辑」菜单（也可用命令面板），仅对 Markdown 文件生效。

- **列表与引用续写**：在列表或引用行尾按回车自动续写标记（任务 / 无序 / 有序列表，含缩进；有序列表序号自动递增）；空列表项上按回车取消标记。
- **任务勾选**：`Ctrl+Alt+T` 在 `[ ]` 与 `[x]` 间切换，普通列表项会自动补上勾选框。
- **表格**：光标放在表格内，用表格子菜单插入 / 删除行列；Tab / Shift+Tab 在单元格间移动，末格按 Tab 在表尾新建一行；「格式化对齐」按内容宽度对齐管道符，并**保留**已有的 `:---:` / `---:` 对齐标记；「左对齐当前列 / 居中当前列 / 右对齐当前列」只改当前列的分隔标记，不影响其他列。
- **行内格式**：`Ctrl+Alt+B` 加粗、`Ctrl+Alt+I` 斜体、``Ctrl+Alt+` `` 行内代码、`Ctrl+Alt+K` 链接；选中文字后按键包裹标记，包裹后会**保留文字的选中状态**，再按一次即取消（只选文字、标记在选区外侧时同样能取消；光标停在刚插入的成对标记上时也按一次取消）。选区首尾的空白不会被包进标记，避免标记失效。
- **标题**：`Ctrl+Alt+1`~`6` 设置标题级别，`Ctrl+Alt+0` 清除；同级别再按一次取消。

## 脚注与前辅文 / 后辅文

预览和导出支持三种 Markdown 扩展语法，**只影响显示，源码内容不会被改动**。

- **脚注**：正文中写 `[^1]`，文末另起一行写 `[^1]: 定义文本`；也可以直接写行内式 `^[直接写内容]`。渲染时角标显示为上标数字，定义自动移到文档末尾的脚注区（可点击跳转，带返回箭头）。同一脚注被多处引用时，第二处起显示 `[1:1]` 形式。
- **前辅文**：文档**开头**的 `---…---` YAML 键值块（`title:`、`tags:` 等）按元数据处理，预览与导出中不可见。
- **后辅文**：文档**末尾**的 `---…---` 键值块同样不可见，适合记录 `status:`、`revision:` 等管理信息。
- 防误判：正文中间的 `---`、正文末尾单独一条 `---`（水平线）、非法 YAML 或列表内容，都会按普通正文正常渲染，不会被当作辅文吞掉。

## 插入图片

- 在 Markdown 文档中通过「编辑 → 插入图片」、命令面板或 `Ctrl+Shift+I` 选择本地图片；也可以直接粘贴剪贴板里的图片（截图或复制的图片文件），或把图片文件拖进编辑器。
- 图片会复制到笔记所在目录的 `PanzerNote_assets/` 文件夹，文档中写入相对路径（如 `![](PanzerNote_assets/xxx.png)`）；落盘文件名会被改写为 ASCII 安全名。
- 若图片本来就在**当前笔记自己的** `PanzerNote_assets/` 里，再次插入只新增一条引用、不会复制出副本。
- 支持常见格式，也支持 **HEIF / HEIC 与 TIFF** 等预览渲染不了的格式：这类图片会在落盘前自动转码成 PNG（带透明通道）或 JPEG，因此插入后预览与导出都能正常显示——**源文件只读，不会被改动或覆盖**。（相机 RAW 不支持：解码依赖体积过大，未纳入。）
- 旧笔记里已有的 `assets/` 目录不会被迁移，原有引用照常显示。
- 导出 HTML 时本地图片会内嵌进文件（单文件自包含）；导出 PDF 会按笔记所在目录解析图片。若个别本地图片内嵌失败（文件缺失或被占用），导出后会给出提示，不会静默丢图。

## 图片查看与清理

- **在文件树里看图片**：图片文件（png / jpg / gif / webp / bmp / svg / tif / tiff / ico / tga / heic / heif / avif 等）会正常显示在文件树中，双击即在**编辑区以标签页打开**（和文档标签一样，可随时关闭；重复双击同一张图只会切到已打开的标签，不会开一堆）。默认适应窗口（只把大图缩小，比窗口小的图按原始像素显示，不会拉伸），单击在「适应窗口 ⇄ 原始大小」间切换，大图可滚动查看；底部状态行显示像素尺寸与当前显示尺寸。竖拍照片会按 EXIF 方向正确显示。在文件树里删除图片（含删除整个目录）会关闭对应标签；重命名后标签自动跟随更新。
- **查看是只读的**：查看图片不会写回、不会重新压缩、不会修改或覆盖原文件。
- **清理未使用的图片**：删除笔记或删掉笔记里的图片引用后，落盘的图片文件不会自动删除。执行「编辑 → 清理未使用的图片...」（或命令面板）会扫描出**没有被任何 Markdown 引用**的图片并列出清单，勾选后「移入回收站」——默认一个都不勾选，确认后才删除，删错了可以从回收站还原。若扫描范围过大导致结果不可信（如引用的笔记过多），本次会直接跳过清理，不做猜测性删除。

## 图片资源与断链恢复

图片与笔记的相对位置很关键：整个文件夹一起移动，图片仍然正常。

- **程序内移动 / 另存为 / 复制文档**：会同时搬运文档引用的图片。只有本文档引用的图片跟着移动，其他笔记也在用的图片则复制一份（不破坏原笔记）；目标目录已有同名但内容不同的图片时自动改名（`xxx_1.png`）并改写本文档的引用，绝不覆盖已有文件。
- **在资源管理器里移动笔记**：程序不监控外部文件操作。只移动 `.md` 而没带上 `PanzerNote_assets/` 时，图片会失效；下次打开文档或建立预览时，会用小秘书气泡和状态栏**非打断**提示缺失情况，不弹对话框。
- **恢复缺失的图片**：执行「编辑 → 恢复缺失的图片...」（或命令面板）→ 确认清单 → 「开始恢复」。恢复只把图片放回文档期望的位置，**不会改动 Markdown 内容**：
  - 仅本文档需要这张图 → 移动回来（旧位置副本删除）；
  - 其他笔记仍在引用 → 只复制一份，旧位置保留；
  - 找不到线索、候选文件已不存在或内容已被改动、同名候选内容不一致 → **不猜**，列入「需人工处理」交给用户判断。
  - 索引里没有任何线索时（例如图片是在早期版本或程序外放进来的），会退一步在**工作区与文档所在目录**范围内按文件名扫描 `PanzerNote_assets/` 找候选：唯一命中即可恢复；多个同名且内容不一致仍交给用户判断。
- 恢复依据是 PanzerNote 记录的图片索引（`用户数据目录/data/config/image_assets.json`）加上磁盘上的真实文件与真实引用。索引只是线索，可删除并自动重建；真正的工作状态始终是 Markdown 与文件系统本身。

## 主题、插件与导出

- 在「设置 → 主题管理」中切换浅色或深色主题，主题会记住上次选择。
- 在「设置 → 插件管理」中启用可信插件。插件运行在主进程内，只安装可信来源的插件。
- Markdown 可通过文件菜单导出为 HTML 或 PDF；导出内容会经过安全渲染。

## 数据与安全

程序不依赖网络，笔记和存档保存在本机。请定期备份用户数据目录；程序不会替你加密笔记或游戏存档。
