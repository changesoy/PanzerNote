# PanzerNote v2.5.0

一款以《战车少女》为主题的离线单机记事本。通过书写获取资源，建造收集角色，点亮完整图鉴。

## 特性概览

- **多标签文本编辑**：行号、语法高亮、自动缩进、括号配对、行操作、大小写转换、JSON/XML 格式化
- **分屏与共享文档多视图**：垂直/水平分屏、分屏状态持久化、标签跨分屏拖拽、同一文档跨面板联动编辑
- **Markdown 分屏预览**：源码行号同步、代码块高亮、一键复制、本地图片支持、脚注 / 前辅文 / 后辅文渲染、正文/代码块行距、代码字体与预览行宽可调（预览行宽可独立选择「限制行宽 / 不限制行宽」，与编辑器的行宽模式互不影响）
- **Markdown 编辑辅助**：列表 / 引用块回车续写（有序序号递增）、`Ctrl+Alt+T` 任务勾选切换、表格插入 / 删除行列与 Tab 单元格导航（格式化对齐保留 `:---:` 标记，另有左 / 中 / 右列对齐）、行内格式（加粗 / 斜体 / 行内代码 / 链接，再按一次取消）、`Ctrl+Alt+1..6` 标题级别
- **Markdown 图片工作流**：选图 / 粘贴截图 / 拖入图片自动落盘到笔记同级 `PanzerNote_assets/` 并写入相对路径（已在本文档资源目录内的图片只新增引用、不复制副本）；程序内移动 / 另存为 / 复制文档时自动搬运图片（独占走 Move、共享走 Copy，同名冲突自动改名不覆盖），程序外移动后可用「恢复缺失的图片」按索引线索 + 真实引用扫描 + hash 校验找回，索引无线索时按文件名兜底扫描，证据不足不猜
- **图片查看器与格式支持**：文件树内双击图片即在编辑区**以标签页**打开查看（适应窗口只缩不放 ⇄ 原始大小、大图可滚动、重复双击复用同一标签）；除常见格式外支持 HEIF / HEIC 与 AVIF；**查看全程只读**，不写回不改动源文件；非常规格式插入文档时自动转码为 PNG / JPEG 以保证预览显示；「清理未使用的图片」可一键列出未被任何 Markdown 引用的图片并移入回收站（相机 RAW 因解码依赖体积过大未纳入支持）
- **数学公式与图表**：KaTeX 行内（`$…$`）与块级（`$$…$$`）公式、Mermaid 图表（流程图/时序图/甘特图等）在预览、HTML 与 PDF 导出三处一致渲染；资产随包内联，断网可用
- **代码缩略图 (Minimap)**：鸟瞰图导航，块级缓存增量失效
- **增强型查找替换**：正则、大小写敏感、全词匹配、匹配计数
- **命令面板 / 跨文件搜索 / Markdown 大纲**：项目内快速导航
- **主题系统**：Theme v2（浅色/深色双变体、recipe 组件库、语法与预览配色统一 token）、弹窗与浮窗深色化、原生标题栏深色
- **书写获取资源**：在线/离线挂机、打字奖励、每日签到
- **小秘书系统**：右下角立绘、台词气泡、自定义角色/皮肤
- **可信插件模型**：能力声明制（capabilities）、命名空间式 PluginContext、事件订阅、启动延迟加载与安全模式、热加载
- **游戏存档**：本地 JSON 保存，后续提供自动备份与损坏恢复

## 安装与运行

### 环境要求

- Python 3.11+
- Windows 10/11
- Microsoft Edge WebView2 Runtime（Markdown 预览与 PDF 导出依赖；Windows 11 与多数 Windows 10 已预装，缺失时启动会给出安装指引）

### 安装依赖

```bash
pip install -e ".[all]"     # 完整安装（格式化 + 开发/测试依赖）
pip install -e ".[format]"  # 仅加装格式化依赖
pip install -e "."          # 核心依赖（已包含预览与图片查看功能）
```

> 可选依赖分组见 `pyproject.toml`：`format`（PyYAML / tomli / tomli-w / cssbeautifier / html5lib）、
> `dev`（pytest / pytest-cov / pytest-qt / pytest-timeout / mypy）、`all`（前两组之和）。
> 核心依赖中的 `pillow-heif`（HEIF / HEIC 解码）自带原生库，会使 PyInstaller 冻结产物
> 增大约 27 MB（98.8 MB → 126.3 MB）；许可证与随包分发义务见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

### 运行

```bash
python main.py
```

首次运行会弹出对话框引导选择数据存储路径。

## 安全与限制

- **离线本地应用**：所有数据存储在本地 JSON 文件中，不依赖网络
- **可信插件模型**：插件运行在主程序进程中，权限系统只限制 PanzerNote 暴露的 API，**不是完整安全沙箱**。请只安装可信来源的插件
- **保存安全**：笔记与存档写入采用同目录临时文件 + 原子替换，崩溃/断电不会留下半写文件；同一文档跨面板并发保存由 Document 级保存状态机保证安全合并
- **游戏存档**：PanzerNote 不提供笔记文件或游戏存档加密。如需保护本机数据，请使用系统账户权限、磁盘加密或加密文件夹工具。
