# 路线图

本文件记录 PanzerNote 尚未完成的功能规划与后续方向。已完成功能请参考 [CHANGELOG.md](../CHANGELOG.md)，架构设计请参考 [architecture.md](architecture.md)。

## 未完成规划

### 建造系统

投入资源建造角色，按一定配方和概率产出不同稀有度的战车娘。建造结果写入图鉴并解锁对应立绘。

- 资源投入面板（燃料/弹药/钢材/铝材配比）
- 建造配方与产出概率表
- 建造队列与时间机制
- 建造结果展示与立绘解锁

### 图鉴收集

收集所有战车娘角色，按编号/类型/阵营分类展示，记录解锁状态、大破立绘和皮肤。

- 图鉴主界面（网格/列表视图切换）
- 角色详情页（立绘/属性/台词）
- 已收集/未收集统计
- 皮肤解锁条件

### 车库

管理已获得的战车娘，编队、强化、退役等操作。

- 角色列表与筛选
- 编队系统
- 强化与升级
- 退役与资源回收

### 游戏设置界面

完善游戏相关设置对话框，统一管理游戏内选项。

- 资源参数配置
- 难度调节
- 音效与提示开关
- 游戏存档导入/导出

## 图片资源管理（已完成）

Markdown 图片工作流（E1–E6 与收尾）已完成：图片落盘到笔记同级的 `PanzerNote_assets/`，文档写入相对路径，并配套资源归属、断链恢复、查看与清理。

- ✅ 插入图片：编辑菜单 / 命令面板 / `Ctrl+Shift+I` 选图，粘贴剪贴板截图与拖入图片文件（E1–E4）
- ✅ managed-asset ledger：`data/config/image_assets.json` 隐藏恢复索引（名称 / 最后已知路径 / sha256 / 尺寸 / 来源），只作「最后已知线索」，不取代 Markdown 与文件系统作为真实状态（E6a）
- ✅ 缺失检测：文档打开 / 建立预览时做 Python 侧只读扫描，经小秘书气泡与状态栏**非打断**提示，不与渲染循环绑定（E6b）
- ✅ 资源迁移：程序内移动 / 另存为 / 复制文档时，按「确认独占 → Move；确认共享 → Copy」搬运图片；目标同名冲突自动改名 `x_1.png` 并定点改写引用，绝不覆盖现有文件（E6c1）
- ✅ 外部移动恢复：「编辑 → 恢复缺失的图片...」按 ledger 线索 + 真实引用扫描 + hash 校验恢复断链；证据不足时不猜，交给用户判断（E6c2）
- ✅ 零拷贝引用：来源已是当前文档自己的 `PanzerNote_assets/` 时只新增引用、不复制副本；其他文档 / 其他位置仍复制落盘以保持自包含
- ✅ 恢复兜底扫描：ledger 无线索时在「工作区 + 文档所在目录」内按文件名扫描 `PanzerNote_assets/` 找唯一候选；有线索但文件已删或内容已改仍不猜
- ✅ 图片查看器：文件树列出图片文件，双击在编辑区**以标签页**打开（适应窗口只缩不放 ⇄ 原始大小单击切换、大图可滚动、重复打开复用同一标签）；支持 Qt 原生格式 + HEIF/HEIC + AVIF，**查看全程只读**；非常规格式插入文档前自动转码为 PNG/JPEG
- ✅ 孤儿图片清理：「编辑 → 清理未使用的图片...」列出未被任何 Markdown 引用的图片，**默认全不勾选**，确认后移入回收站（可还原）并同步清理索引记录

仍未纳入：旧 `assets/` 目录迁移命令、浏览器侧预览健康诊断、相机 RAW 查看（解码需 LibRaw + numpy，约 54 MB 包体，成本与收益不成比例）。
