# PanzerNote 用户指南

PanzerNote 是一款离线、本地优先的 Markdown 与文本编辑器，主题取材自《战车少女》：
书写笔记即可获取游戏资源，逐步建造、收集角色并点亮图鉴。

本指南面向终端用户，覆盖从安装到日常使用的完整流程。应用内还有两份速查文档：
「帮助 → 使用说明」（功能操作速查）与「帮助 → 快捷键列表」（可查看并自定义全部快捷键）。

- 安装步骤与运行环境见 [README](../README.md#安装与运行)。

## 首次启动

1. 按 README 完成依赖安装后运行 `python main.py`。
2. 首次运行会弹出对话框，引导你选择一个**用户数据目录**。笔记、设置、工作区状态
   与游戏存档都会保存在这里——请选择一个你会定期备份的位置。
3. 在「设置」中按个人习惯检查编辑器字体、换行符、主题和窗口选项。
4. 在文件树中确认「工作」「回忆」「日记」等笔记分类已创建，即可开始写第一篇笔记。

## 界面总览

- **编辑区**：多标签页，支持分屏（同一文档可跨面板联动编辑，也可打开独立文件）。
- **文件树**（左侧）：浏览笔记目录与外部文件，支持拖拽移动 / 复制。
- **大纲面板**：按标题跳转当前 Markdown 文档。
- **跨文件搜索面板**：在整个工作区内搜索文本。
- **命令面板**：快速执行任意命令，不必记忆菜单位置。
- **状态栏**：显示当前文档统计、行尾符、大文件指示、预览健康状态等信息。
- **游戏侧栏**：资源、签到、挂机等游戏系统入口；右侧是小秘书立绘与台词气泡。

按 `Esc` 可逐级退出子页面与面板（快捷键列表、大纲 / 搜索面板、游戏页面），文件树属于
主界面不受影响。

## 文件管理

- **新建 / 打开 / 保存**：全部在「文件」菜单；关闭窗口或标签页时会提示处理未保存内容。
- **自动保存**只用于异常恢复，**不替代手动保存**——日常请养成 `Ctrl+S` 习惯。
- **拖拽移动 / 复制**：把标签页或文件树条目拖到目标上：落在文件夹进该文件夹，落在文件
  进其所在文件夹，落在列表下方空白处进笔记库根目录。松手后询问「移动还是复制」
  （拖文件夹直接移动）。落点只有真的会生效时才高亮。
- 程序内移动 / 另存为 / 复制文档时，会**一并搬运文档引用的图片**（详见[图片工作流](#图片工作流)）。
- 外部文件可以加入外部文件区浏览，但重要内容建议复制进自己的笔记目录。

## 编辑功能

- **基础编辑**：语法高亮、自动缩进、括号配对、代码折叠、行号。
- **行操作**：上 / 下移动行、复制行、删除行等（见「编辑」菜单与「行操作」子菜单）。
- **大小写转换**与 **JSON / XML 格式化**。
- **查找替换**：支持正则、大小写敏感、全词匹配与匹配计数；跨文件搜索见左侧面板。
- **代码缩略图（Minimap）**：鸟瞰导航，可用「视图」菜单开关。
- **大文件模式**：打开超过 1 万行的文档时状态栏会出现「大文件」指示，此时缩略图、
  自动补全、自动预览刷新会暂时停用以保证流畅；「视图 → 刷新预览」可手动触发渲染。

## Markdown 编辑与预览

- **分屏预览**：Markdown 文件可打开实时预览；预览行宽独立于编辑器行宽模式，可分别设置。
- **编辑辅助**（「工具 → Markdown 编辑」菜单，仅对 Markdown 生效）：
  - 列表 / 引用回车自动续写标记（含缩进，有序列表序号递增）；空列表项回车取消标记。
  - `Ctrl+Alt+T` 任务勾选切换（`[ ]` ⇄ `[x]`）。
  - 表格子菜单：插入 / 删除行列、Tab 在单元格间移动、格式化对齐（保留既有对齐标记）、
    左 / 中 / 右列对齐。
  - 行内格式：`Ctrl+Alt+B` 加粗、`Ctrl+Alt+I` 斜体、``Ctrl+Alt+` `` 行内代码、
    `Ctrl+Alt+K` 链接；再按一次取消。
  - 标题级别：`Ctrl+Alt+1`~`6` 设置，`Ctrl+Alt+0` 清除；同级再按取消。
- **扩展语法**（只影响渲染，不改动源码）：
  - 脚注：`[^1]` 引用 + 文末 `[^1]: 定义`，或行内式 `^[直接写内容]`。
  - 前辅文 / 后辅文：文档开头或末尾的 `---…---` YAML 键值块按元数据处理，渲染中不可见。
- **数学公式与图表**：KaTeX 行内 `$…$` 与块级 `$$…$$`、Mermaid 图表，在预览与
  HTML / PDF 导出中一致渲染，断网可用。

## 图片工作流

- **插入图片**：「工具 → 插入图片」、`Ctrl+Shift+I`、直接粘贴剪贴板截图，或把图片文件
  拖进编辑器。图片自动复制到笔记同级的 `PanzerNote_assets/`，文档写入相对路径。
- **格式支持**：常见格式外还支持 HEIF / HEIC / AVIF / TIFF；渲染不了的格式落盘前自动
  转码为 PNG 或 JPEG，源文件只读不改动。相机 RAW 不支持。
- **图片查看器**：文件树中双击图片即在编辑区以标签页打开（只读查看：适应窗口 ⇄
  原始大小，大图可滚动，EXIF 方向正确）。
- **移动与恢复**：程序内移动文档会带上图片；若在资源管理器里只移动了 `.md` 导致图片
  失效，用「工具 → 恢复缺失的图片...」按索引线索 + 真实引用找回——证据不足的不会猜测，
  会列入「需人工处理」。
- **清理与迁移**：「工具 → 清理未使用的图片...」列出未被引用的图片，勾选后移入回收站
  （可还原）；「工具 → 迁移旧图片目录...」把早期版本的 `assets/` 统一迁入
  `PanzerNote_assets/` 并改写引用，执行前有完整预演清单。

## 导出

- 「文件」菜单可将 Markdown 导出为 **HTML**（单文件自包含，本地图片内嵌）或 **PDF**。
- 导出始终使用浅色配色方案（黑字浅底），无论当前应用处于什么主题，保证白纸可读。
- 数学公式、Mermaid 图表与代码块高亮在导出中与预览一致。
- 若个别本地图片内嵌失败（缺失或被占用），导出后会给出提示，不会静默丢图。

## 主题与插件

- **主题**：「设置 → 主题管理」切换浅色 / 深色主题，选择会被记住；编辑器、预览、
  对话框、状态栏全部跟随主题。主题包格式与自制方法见
  [主题作者指南](theme-design/theme_authoring.md)。
- **插件**：「设置 → 插件管理」启用可信插件。插件运行在主进程内，权限由能力声明
  （capabilities）控制——这不是完整安全沙箱，**只安装可信来源的插件**。开发文档见
  [插件开发](../plugins/plugin_api.md)。

## 游戏系统

- **书写获取资源**：持续输入文字会累计今日书写统计并产生资源；另有在线 / 离线挂机收益。
- **每日签到**：首次启动发放签到奖励，资源栏显示当前资源与统计。
- **小秘书**：右下角立绘与台词气泡，可自定义角色 / 皮肤，也会用气泡做非打断提示
  （如图片缺失）。
- **建造 / 图鉴 / 车库**：规划中（见 [路线图](roadmap.md)）。

## 数据与备份

- 程序完全离线，笔记与存档都存在你选择的本机用户数据目录中，不上传任何数据。
- **请定期备份整个用户数据目录**——不要只备份单个 JSON 文件。升级或迁移前先整体备份。
- 程序不提供笔记或存档加密；如需保护数据，请使用系统账户权限、磁盘加密或加密文件夹工具。
- 笔记写入采用同目录临时文件 + 原子替换，崩溃 / 断电不会留下半写文件。

## 常见问题

**Q：预览打不开或显示异常？**
检查状态栏的预览指示（预览依赖 Microsoft Edge WebView2 Runtime，Windows 11 与多数
Windows 10 已预装；缺失时启动会给出安装指引）。点击状态栏指示可查看诊断原因与修复建议。

**Q：在资源管理器里移动了笔记，图片全裂了？**
用「工具 → 恢复缺失的图片...」；下次移动请优先用程序内的拖拽 / 另存为，它会连图片一起搬。

**Q：打开大文件后缩略图 / 补全 / 自动预览不见了？**
这是大文件模式的预期降级（状态栏有「大文件」指示）。需要预览时用「视图 → 刷新预览」
手动渲染。

**Q：程序异常退出会丢稿吗？**
笔记写入是原子替换，不会留下半写文件；自动保存提供异常恢复（内容与行尾一并还原）。
重启后按提示查看崩溃日志。
但**自动保存不替代手动保存**，请保持保存习惯。

**Q：换行符显示不对 / 想改行尾？**
点击状态栏的行尾符指示可切换；行尾切换可以撤销（会正确计入脏状态）。

**Q：快捷键能改吗？**
「帮助 → 快捷键列表」可查看、修改全部快捷键，标题行右侧「重置全部」可恢复默认。
