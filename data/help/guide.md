# 新手攻略

本页是一条从第一次启动到形成日常使用习惯的路线，不展开每个按钮的完整定义。

## 第一步：完成首次配置

1. 启动程序，在首次运行对话框中选择一个专门的数据目录。
2. 在文件树中确认「工作」「回忆」「日记」等笔记分类已经创建。
3. 打开「设置」检查编辑器字体、换行符、主题和窗口选项。

## 第二步：建立第一篇笔记

1. 使用「文件 → 新建」，立即保存到合适的分类目录。
2. 如果要写 Markdown，使用 `.md` 扩展名，然后打开预览确认标题、列表和代码块效果。
3. 需要查资料时，可以把外部文件加入外部文件区，但重要内容建议复制或保存到自己的笔记目录。

## 第三步：让书写参与游戏循环

- 持续编辑或输入文字会累计今日书写统计，并产生对应资源。
- 每日首次启动会发放签到奖励；资源栏会显示当前资源和统计数据。
- 当前版本已提供资源、签到、挂机收益和小秘书等基础机制；建造、图鉴、车库和游戏设置仍在规划中。

## 推荐的日常流程

**打开程序 → 查看今日资源 → 写一段笔记 → 保存 → 检查 Markdown 预览 → 关闭前确认没有未保存标签。**

## 遇到问题时

- 先查看「帮助 → 使用说明」和「帮助 → 快捷键列表」。
- 如果程序异常退出，重新启动后按提示查看崩溃日志。
- 升级或迁移前，先备份整个用户数据目录，不要只备份单个 JSON 文件。
